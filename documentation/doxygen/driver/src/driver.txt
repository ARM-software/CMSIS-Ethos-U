| \c pmu_ethosu.h | Public umbrella header for the \ref ethosu_pmu_api. |
| \c ethosu_pmu_funcs.h | \ref ethosu_pmu_api function declarations. |
| \c ethosu_pmu_types.h | \ref ethosu_pmu_api types, event identifiers, and counter masks. |
| \c ethosu_log.h | Private compile-time logging interface documented in \ref ethosu_log_api. |
