Description

Driver definitions, types, and functions.

The public driver interface is provided by two headers. This group contains the core driver types, functions, and platform-specific functions from ethosu_driver.h. Compile-time logging from the private ethosu_log.h header is documented in Logging. The Performance Monitoring Unit interface from pmu_ethosu.h is documented in Performance Monitoring Unit API.
